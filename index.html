Player Player Commands

/power (alias: /p)
Shows your current power, kills, keybinds, and ability 2 unlock status.
Default — all players
/power info [power]
Shows detailed info about a power: rarity, passive, abilities, cooldowns, and kill requirements.
[power] — optional power name
Default — all players
/power list
Lists every power with rarity weight and kill requirement.
Default — all players
/power bind <ability> <key>
Rebinds ability 1 or ability 2 to a different key.
<ability> ability1 | ability2  ·  <key> F | RIGHT_CLICK | LEFT_CLICK | SHIFT_F | SHIFT_RIGHT_CLICK | SHIFT_LEFT_CLICK
Default — all players
/power recall
Despawns all your active minion companions.
Default — all players
/power buff
Opens the Token Buff Shop. Spend tokens for Speed, Strength, Resistance, Haste, and more.
Default — all players
/powers
Opens the Powers Guide GUI — a paginated browser of all powers with details.
Default — all players

OP Operator Commands

/power give <player> <power>
Forces a specific power onto a target player. Resets kills, cooldowns, and ability 2 lock.
<player> target name  ·  <power> power name (e.g. Speed, Necromancer)
Requires op — powers.give
/power reroll [player]
Rerolls a player's power. If no player is given, rerolls your own.
[player] — optional target name
Requires op — powers.give
/power test
Enables test mode: all cooldowns bypassed, ability 2 always unlocked server-wide.
Requires op — powers.give
/power normal
Disables test mode and re-enables normal cooldowns and kill-based unlocks.
Requires op — powers.give
/grace [time]
Starts a PvP grace period. PvP is disabled across all worlds for the duration.
[time] 30s | 10m | 2h  (default: 10m)
Requires op — powers.give
/grace off
Immediately cancels the active grace period and re-enables PvP.
Also accepts: stop, end
Requires op — powers.give
